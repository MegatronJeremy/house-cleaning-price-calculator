# House Cleaning Price Calculator

![House Cleaning Price Calculator screenshot](screenshot.png)

Work out what to charge per house-cleaning job so it pays your hourly target, free and in your browser.

**Live:** https://megatronjeremy.github.io/house-cleaning-price-calculator/

Static page served from the repo root (copies also in `/docs`) on GitHub Pages. Plain HTML/JS, no dependencies, nothing is sent anywhere after the page loads (CSP `default-src 'none'`). AI-assisted. Links to the paid spreadsheet kit (we earn money if you buy it) with `?utm_source=pages_cleaning`.
